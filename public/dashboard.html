GET STARTED

3ステップで接続

  1. 01

    開発用拡張機能を読み込む

    ZIPをダウンロードして展開。Chromeの拡張機能管理でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」から展開したフォルダーを選びます。

    拡張機能をダウンロード

    スクリプトを用意する

    ビルド済みファイルを、Tampermonkeyの新しいスクリプトに貼り付けて保存します。

    スクリプトをダウンロード

    どちらか一方だけを有効にしてください。

  2. 02

    ChatGPTを開く

    ログインしてChatモードを選び、ページを再読み込みします。

    ChatGPTを開く
  3. 03

    接続を確認する

    ChatGPTの右下に「LocalGPT · 接続済み」と表示されたら準備完了。このページの接続状態も自動で更新されます。

APIエンドポイント

POST

Base URL

http://localhost:8766/v1

Responses API

/responses

最初のリクエスト

curl -N http://localhost:8766/v1/responses \
  -H 'Content-Type: application/json' \
  --data '{"input":"こんにちは！","stream":true}'

接続後にターミナルから実行できます。モデルはChatGPTの画面で選択してください。MCPの入口は /mcp、モデル表示名の取得は /v1/models です。
